# Perfect Pull! の紹介サイト

`fav_list_ai/website` のデザインを踏襲している。**構造とクラス名はそのまま**で、
配色だけをアプリの identity（起動画像の青と金）へ差し替えた。

App Store: <https://apps.apple.com/app/id6806810305>
（**ストアフロントを指定しない形**を使う。Apple が閲覧者の国のストアへ振り分ける）

## 中身

| ファイル | 内容 |
|---|---|
| `index.html` / `index_jp.html` | 紹介ページ（英語 / 日本語） |
| `privacypolicy.html` / `privacypolicy_jp.html` | プライバシーポリシー（英語 / 日本語） |
| `styles.css` | 参照元から複製し、配色とスクリーンショットの並びを足した |
| `app-ads.txt` | **AdMob の収益に必要。** 参照元と同じ発行者ID |
| `images/screenshots/en/` `images/screenshots/ja/` | 画面のスクリーンショット。`store/screenshots/source/<lang>/` を `sips -Z 900` で長辺900pxへ縮小したもの（414×900）。**言語ごとに分けてある**（英語ページは `en/`、日本語ページは `ja/`）。以前は日本語版1組だけを両方のページで使っており、英語ページに日本語の画面が出ていた |

## 参照元との違い

- **端末プレビューに実物のスクリーンショットを入れている**（参照元は CSS で作った模型）
- **写真・カメラの節を書いていない。** 本アプリはそれらへのアクセスを求めない
- **「プライバシー設定」画面への案内を書いていない。** 本アプリにその画面は無い。
  参照元（OkiniIre）にはあるため、そのまま写すと**存在しない機能を案内することになる**
- App Store のバッジとリンクを置いていない。**まだ公開されていないため**

## 公開前に直すもの

1. **App Store のリンク。** 公開後、`index.html` / `index_jp.html` の
   `download-band` にバッジを置く（`images/AppStore-De-DownLoad.svg` は用意済み）。
   `eyebrow` の「まもなく」「Coming soon」も変える
2. **プライバシーポリシーの URL** を App Store Connect に登録する

## 確認したこと

ブラウザで 1280px と 375px の両方を表示し、次を確認した。

- 横スクロールが出ないこと、画面外へ溢れる要素が無いこと
- 7枚の画像がすべて読めること、縦横比が崩れていないこと
- スクリーンショットの並びが 4列 → 1列へ落ちること
- 内部リンクに切れが無いこと（4ページ分を機械的に照合）
